# MOC – webbplats

Statisk, responsiv webbplats för **Military Order of the Collar of Saint Agatha of Paternò (MOC)**.

## Sidor

- `index.html` – startsida med historik, gemenskap, priorat, stiftelser och humanitära projekt.
- `priorat.html` – översikt över priorat.
- `priorat-detalj.html` – sidor för respektive priorat.
- `st-peter-nolasco.html` – artikel om en ceremoni.

## Visuell riktning

Startsidan använder vinrött, guld, elfenbensvitt och mörkblått. Layouten förenar tre teman: **historiskt arv**, **ceremonier och gemenskap** och **hjälpverksamhet**. Samma färgpalett används på undersidorna.

**Viktigt om bilder:** Fotografierna som för närvarande används från Unsplash är *illustrationsbilder*. De föreställer inte verifierade MOC-ceremonier, insignier eller projekt. Ingen AI-genererad ordenssymbol används som officiell logotyp. En textbaserad MOC-signatur används tills godkänd originalfil finns.

## Innan officiell lansering

1. Byt illustrationsbilder mot MOC:s egna godkända fotografier, särskilt ceremonier och hjälpverksamhet.
2. Lägg in officiell logotyp och autentiska insignier i originalformat.
3. Kontrollera historiska påståenden, titlar och datum mot godkända källor.
4. Verifiera att beskrivna hjälpinsatser är aktuella och att publiceringstillstånd finns.
5. Bekräfta kontaktuppgifter och översättningar för alla språk.

## Publicering

Projektet har GitHub Pages-flödet `.github/workflows/deploy-pages.yml` som publicerar ändringar från `main`, förutsatt att GitHub Pages är aktiverat i projektets inställningar.

Ändringar bör granskas i en pull request innan de förs in i `main`.
